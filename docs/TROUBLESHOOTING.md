# Troubleshooting

- Database unavailable: check `docker compose ps`, PostgreSQL healthcheck, and `DATABASE_URL`.
- Code rejected: verify the code has not expired, was generated by device API, and has not been claimed.
- Code expired: press the physical terminal button again.
- ESP32 cannot connect: verify Wi-Fi secrets, API URL, and Cloudflare certificate strategy.
- LCD blank: check I2C address `0x27`, SDA/SCL wiring, and power.
- Cloudflare 404: check ingress order and final `http_status:404` rule.
- Socket.IO failure: the web app falls back to polling; check tunnel websocket support and browser console.
- Stale READY orders: mark them `PICKED_UP` from the kitchen dashboard.
- Migration failure: restore the latest backup, inspect `migration_history`, then rerun `npm run migrate`.
